# Changelog

## [0.1.0] - 2026-11-19

- Initial version: the shortcut stashes the current draft and clears the editor; pressing it again on an empty editor restores the stash unsent.
- Shortcut defaults to Ctrl+Shift+S and is configurable through `.pi/simple-stash.json` (project) or `~/.pi/agent/simple-stash.json` (user).
